## 两种计算方式

**从基函数计算**：选择已验证的 87 个真实空间点群之一，输入代表位置并对称展开，或逐中心输入。添加 s、全局或自定义 p、五个实 d 分量；程序逐函数构建 D(g)、识别当前基下的封闭块、计算特征标，并自动约化全体及各块。点群范围为 C1/Cs/Ci；Cn/Cnv/Cnh、Dn/Dnh/Dnd（n=2…12）；S4…S24（偶数）；T/Th/Td/O/Oh/I/Ih。

**手动输入特征标**：保留原程序可选的 423 个有限点群，轴向族 n 至 60、S 至 120。按当前表列顺序输入每类一个值，不乘类大小。逗号或分号分隔，可用 i、π、sqrt、cos、sin、exp、四则运算和幂。保留完整复不可约表示，E+/E− 不合并成一行。分解仍采用 `a = X.conj() @ W @ c / h`，检查非负整数重数及重建误差；非法输入不会输出成功分解。

两条入口使用同一特征标表、类顺序、MathML 数学排版和结果格式。展示 X 的精确公式与根式；实际计算使用双精度，导出保留完整精度及容差，不把数值结果冒充符号证明。输入框的表达式有长度和复杂度限制，不调用 eval。

## SALC 系数

在「从基函数计算」中完成分解后，点击「生成 SALC 系数」，按不可约表示和副本查看。每列给出一个组合 $\psi = \sum_j c_j \phi_j$，行对应原输入函数。复制包含当前副本，完整结果 JSON 包含已生成的全部副本。水示例取 xz 为分子平面，两个 H 1s 函数分别给出 A1 的归一化和与 B1 的归一化差，各系数的绝对值均为 1/√2。

计算使用特征标投影算符 $P_\alpha = \frac{d_\alpha}{|G|}\sum_{g\in G}\chi_\alpha(g)^*D(g)$，星号表示复共轭。对于重复出现的多维表示，程序逐副本构造伙伴函数，检查正交性、生成元下的封闭性及特征标。各中心、径向标识与角动量的组合彼此正交，同组 p 使用方向内积，d 使用张量 Frobenius 内积。整体相位、简并空间中的基和等价副本的选取具有自由度。[MIT 群表示讲义](https://ocw.mit.edu/courses/18-712-introduction-to-representation-theory-fall-2010/24d8b3fa2ce48e48ee6c2d8d5e3562f6_MIT18_712F10_replect.pdf)

## 示例与保存

- 苯 D6h：30 个函数、五个输入批次，自动识别四个封闭块，再分别输出不可约组成。C px/py 联合；C 2s 与 H 1s 保留两个独立等价副本。
- 水 C2v：xz 平面内两个 H 的 s，分解为 A1 + B1。
- 中心 p：C2v 三个独立分量；Oh 三者联合。
- 中心 d Oh：全局坐标五个 d 自动分为 3+2 维块，分解为 T2g + Eg。C2v 五个分量分别封闭，总体为 2A1 + A2 + B1 + B2。
- 二十面体 Ih：+z 代表位置生成十二个 s，分解为 Ag + Hg + T1u + T2u。

保存输入、载入、撤销、导出完整结果、单独导出向量、复制文本和 LaTeX 都在同一应用内完成。0.1–0.3 的基函数 JSON 仍可载入；载入后重新计算，不信任文件内旧结果。手动输入另存为 `input.mode = "manual"`。语言偏好与数学输入分离。

## d 和变换约定

主动操作 `U(g)φ_j = Σ_i φ_i D_ij(g)`；位置 `r → Rr`、p 方向 `u → Ru`。每个中心/径向类型最多三个独立 p；非正交角向基通过 QR 分解展开，并检查重建残差。

d 为五维实球谐函数 dxy、dxz、dyz、dx²−y²、dz²（即 2z²−x²−y²）。对称无迹张量 Q 满足 `f(x)=xᵀQx`；标准张量按 Frobenius 内积正交归一，变换为 `Q → RQRᵀ`。局部轴矩阵 A 的列为 x′/y′/z′ 在全局坐标中的方向，轨道为 `AQ₀Aᵀ`。高级设置输入垂直的 x′、z′，系统生成右手 y′。同批中心共用轴；不同中心可分别选中添加。

d 的中心可在原点或对称相容的非原点位置。JSON 使用 `family:"d"`、`component:"dxy"` 等标识和可选 `frame`；缺省为单位矩阵。径向 ID 是副本标识，不是量子化学基组库。最多 120 个中心、180 个函数。

“封闭计算块”不一定不可约，也不保证是最小不变空间；换基会改变当前块结构。各独立等价副本均保留。六维 Cartesian d、自动点群识别、实际 AO 重叠积分及电子能量尚未实现。

## 模块与验证

几何引擎仍独立；适配器明确映射共轭类，轴向群匹配实际空间矩阵，多面体群保留明确逐类对应。新增约化引擎采用原程序的完整复表及数值算法，生成 423 张解析表。原有 Python 约化代码保持兼容，整合版位于独立目录；同步 `sources/` 未修改，运行整合版无需原 Python 程序。

原数学约定来源：[core.py](https://github.com/lightzfpwings/pointgroup-reducer/blob/main/core.py)、[operation_labels.py](https://github.com/lightzfpwings/pointgroup-reducer/blob/main/operation_labels.py)。固定快照记录检索日期和源文件 SHA-256。测试逐项比较原表数值、列/行名称及每个原不可约行的约化结果，并核验基函数链、复数解析、错误处理、三语切换、复制和旧文件兼容性。

运行 `python3 build.py` 生成离线网页和源码 ZIP，再用 `node --test tests/*.test.js` 执行测试。源码 ZIP 含独立构建所需的文件与测试数据。用 `python3 packaging/build_macos.py` 构建 Mac 应用，需要 Apple 命令行工具。构建会校验签名，并用 JavaScriptCore 运行计算自检。当前封装的自检报告在 `dist/`，历史核验记录随仓库保存在 `validation/`。

## 0.5.0 光谱开发预览

**振动光谱（红外与拉曼）**使用所选空间点群和全部原子坐标，包括位于对称中心的原子。可打开或粘贴单帧 XYZ，也可手填坐标或载入已有项目。XYZ 首行写原子数（1–120），第二行为注释或空行，其后每行写元素和三个以 Å 为单位的坐标。D 和 T 可单独作为同位素类型。

化学式按中性分子的元素数目匹配，支持 `CH4`、`CH₄` 和带括号的写法。离线库收录甲烷、水、氨、二氧化碳、苯、BF₃、SF₆，以及 C₂H₆O 和 C₂H₂Cl₂ 的代表结构。四面体碳或硅与四个 H、F、Cl、Br、I 取代基的组合按组成生成模型。每次只列出已收录或可按这些规则生成的候选。乙醇反式构象和二甲醚采用 NIST 参考几何，其余候选标明为理想化几何。项目 JSON 保存起始模型和实际参与计算的全套坐标。[NIST 乙醇](https://cccbdb.nist.gov/exp2x.asp?casno=64175) · [NIST 二甲醚](https://cccbdb.nist.gov/exp2x.asp?casno=115106&charge=0)

旋转模型，对照原子编号和坐标表，选择 A、B、C 测量 A–B 距离和以 B 为顶点的夹角。XYZ 预览中的灰色连线按共价半径估算，绿色线段连接测量所选的原子。确认时程序检查全部同类型原子在所选点群下的一一映射，并给出最大位置偏差。XYZ 默认取几何中心为对称原点，保留文件的轴向和原始坐标。选择点群时请对照轴向提示，必要时在分子编辑器中对齐坐标后再导入。改变结构、点群、原点或容差后须重新确认。[XYZ 格式](https://openbabel.org/docs/FileFormats/XYZ_cartesian_coordinates_format.html) · [共价半径数据](https://doi.org/10.1039/B801115J)

确认后点击「计算振动与光谱活性」。每个操作的笛卡尔位移特征标为固定原子数乘以空间矩阵的迹。扣除整体平移和转动后，非线性分子有 3N−6 个振动自由度，线性分子有 3N−5 个，单原子为 0。红外允许的振动与偶极矢量同对称性，拉曼允许的振动与对称极化率张量的六个分量之一同对称性。

简并分量按一个基频计，复共轭行也成对计数。选用有限子群时，简并度和计数均服从该子群。峰位需要质量与力常数，强度还需要偶极矩或极化率对简正坐标的导数。可直接载入甲烷 Td 或二氧化碳 D4h 振动示例。甲烷的 9 个振动自由度分解为 A1 + E + 2T2，对应 4 个基频，其中 2 个红外允许、4 个拉曼允许。基频对称性与 NIST 列出的实验归属一致。[NIST 甲烷振动数据](https://cccbdb.nist.gov/exp2x.asp?casno=74828)

以 xz 平面内的水为例，两个 A₁ 振动均允许 z 偏振，并各有三个独立的拉曼张量分量 xx、yy、zz。B₁ 振动允许 x 偏振和 xz 分量。对沿 z 轴的 CO₂，A₁g 行显示「xx + yy, zz」：xx 与 yy 相等，zz 可独立变化。xy、xz、yz 各代表一对相等的非对角元。复制结果保留这些组合，JSON 的 `spectrum.activities` 保存每行的单位偶极方向 `irDirections` 和按 Frobenius 范数归一化的对称矩阵 `ramanTensors`。[计算方法与验收样例](SPECTROSCOPY_DESIGN.md)
