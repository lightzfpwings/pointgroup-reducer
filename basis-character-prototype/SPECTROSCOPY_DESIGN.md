# 0.5.0 振动光谱模块设计

**第一步让用户从分子结构读出偏振选择定则。** 例如，水分子放在 xz 平面，选择 C₂ᵥ 后，用户应能看到两个 A₁ 模式都允许 z 偏振红外吸收，另一个 B₁ 模式允许 x 偏振红外吸收。引入频率和响应数据后，用户再沿同一张表查看谱线、强度和对应的原子位移。

## 目前的基础

振动入口接受单帧 XYZ、手填坐标和已有项目。用户可旋转预览、核对组成并量取原子间距和夹角，再确认所选点群。确认与随后计算共用原子映射和线性判定，保留原坐标、输入轴向和计算采用的对称原点。改变输入几何或对称设置后需重新确认。

只有化学式时，按元素计数查询离线候选，用户选用一个具体异构体或构象后进入同一核对流程。模型带有全部原子、与当前引擎轴向相容的点群，以及理想化几何或参考几何标记。C₂H₆O 可选反式乙醇或二甲醚。C₂H₂Cl₂ 可选 1,1-、顺式-1,2- 或反式-1,2-二氯乙烯。切换候选会撤销上次结构确认和计算结果。项目中的 `input.formulaModel` 记录起始候选，重新打开时从保存的 `sites` 还原几何。[候选模型](formula-models.js)

开发原型已经从 87 个有限点群和全部原子坐标计算笛卡尔位移表示，扣除平移及转动，给出振动不可约组成、简并度、红外和拉曼是否允许，以及允许的基频数。单原子、线性与非线性结构分别有 0、3N−5、3N−6 个振动自由度。这里的基频数按所选群和振动重数计数，偶然频率重合、过弱跃迁和实验分辨率都会影响可观测峰数。[原型](vibrations.js) · [原型测试](tests/vibrations.test.js)

下列三个阶段属于光谱开发线。每阶段都有独立可用的输入与结果。

| 阶段 | 用户输入 | 交付结果 |
|---|---|---|
| 1 · 对称性与偏振 | 点群、完整原子坐标、坐标轴约定 | 振动种类、简并度、选律，以及允许的偶极方向与极化率张量基 |
| 2 · 数值谱线 | 带单位的频率及可选的 IR 积分强度、Raman 散射活性 | 模式表、带权棒谱、可调展宽和数据导出 |
| 3 · 简正模求解 | 原子质量、平衡几何、笛卡尔 Hessian，可选性质导数 | 谐振波数、位移向量、对称性归属、由导数得到的光谱量 |

## 第一阶段 · 从对称性读出偏振

复用原型的原子置换与群操作。对操作矩阵 $R$，位移特征标为固定原子数乘 $\operatorname{tr}R$。整体平移按 $R$ 变换，整体转动按 $\det(R)R$ 变换，线性分子须移除绕分子轴的零位移。原子选取使用整个分子，与轨道 SALC 页勾选了哪些原子相互独立。

用同一组操作及已对齐的特征标表，把偶极空间 $(x,y,z)$ 和六维对称张量空间分别投影到每种振动对称性。在张量空间使用 Frobenius 正交基，非对角基取 $(e_i e_j^T+e_j e_i^T)/\sqrt{2}$，按 $T\mapsto RTR^T$ 变换，保留全对称的各向同性分量。标出独立的方向或张量组合，并将组件换算到通常的 $\alpha_{xy}$ 等记号。原型中现有的投影与表示验证算法可复用，轨道内积及 AO 系数只适用于轨道工作流。

结果表增加「IR 偏振」「Raman 张量」两列。C₂ᵥ 水的 A₁ 行应显示 z 和 xx、yy、zz，B₁ 行应显示 x 和 xz。换到 yz 分子平面，反对称伸缩的标签变为 B₂，偏振随之变为 y 和 yz。多维表示展示整个允许子空间，坐标轴旋转时同步变换张量。多个同种模式可以具有不同的张量系数，数值由性质导数确定。

实位移空间中，复共轭的一维不可约行成对给出一组二维实基。界面保留两行的原始标签。CO₂ 使用 D₄ₕ 有限子群时保留二重简并弯曲，结果附所选子群。若用户选用 D₂ₕ，则列出两个子群分量。原子类型可区分同位素，原子质量进入计算后，每个对称置换还须保持质量。

## 第二阶段 · 从外部数据画谱

先实现按模式导入的 JSON，再用有测试样本的 ORCA 输出适配同一接口。每条记录保留源文件中的模式编号、波数与单位，可选对称性、IR 积分强度、Raman 散射活性、简并组及数据来源。输入须说明记录对应单个分量还是整个简并组。文件只提供波数时，在横轴显示峰位标记，并把缺失强度留空。缺少位移或标签时，即使波数接近，也没有足够依据自动认定模式的对称性。

波数和展宽半高全宽均用 cm⁻¹，IR 积分强度用 km/mol，Raman 活性用 Å⁴/u。按高斯或洛伦兹线型展宽时，对每条线作单位面积归一化，使曲线面积与输入权重一致。分量强度可按已确认的简并组求和，来源为整组的强度只计一次。拉曼图的初始纵轴标为散射活性，后续引入激光波长、温度及散射模型后再提供相对 Stokes 强度。导出记录坐标轴、单位、线型、半高全宽和归一化设置。[ORCA 振动光谱手册](https://www.faccts.de/docs/orca/6.1/manual/contents/spectroscopyproperties/vibrations.html)

## 第三阶段 · 从 Hessian 求波数与归属

1. 输入约定为平衡几何处、尚未质量加权的 $3N\times 3N$ 笛卡尔 Hessian。记录原子 ID、原子顺序、每个原子的 xyz 顺序、实际同位素质量及单位。优先支持长度 Å、质量 u 和 Hessian 单位 Hartree/bohr²。适配器转换到统一单位并保留来源。检查有限值、正质量、矩阵维数与对称残差。坐标、质量、导数和 Hessian 必须对应同一原子序列及坐标系。
2. 在质心坐标中构造质量加权的平移与转动向量，求其正交补 $B$。在该空间对角化 $B^T M^{-1/2}H M^{-1/2}B$。按 SI 单位计算时，本征值的单位为 s⁻²，正值对应的波数为 $\sqrt{\lambda}/(2\pi c)$，其中 $c$ 用 cm/s。显著负值保留为虚频，接近零的数值连同容差单独标记。位移用 $M^{-1/2}B l_k$ 恢复，质量度量下归一化。[ORCA 频率计算手册](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/frequencies.html)
3. 检查质量加权 Hessian 与群操作的相容性，用投影权重给模式或简并子空间分配标签。先用相邻波数筛选候选分组，再核对各组的群作用。对称性不同的模式即使同频也分别保留。等价表示可以混合，同一简并空间内的向量允许正交旋转。对称性残差过大时保留原始波数和残差，标注归属未定。
4. 若有笛卡尔偶极矩或极化率导数，将其与同一质量归一化约定的位移收缩，得到 $\partial\mu/\partial Q_k$ 或 $\partial\alpha/\partial Q_k$。强度换算须使用明示的导数单位。选定的入射、散射偏振分别为 $e_i,e_s$ 时，偏振 Raman 权重与 $\lvert e_s^T(\partial\alpha/\partial Q_k)e_i\rvert^2$ 成正比。简并组的总权重应在伙伴函数换基下保持一致。

## 验收样例

| 样例 | 可复核的结果 |
|---|---|
| H₂O，C₂ᵥ，xz 平面 | 2A₁+B₁，3 个红外允许、3 个拉曼允许基频。交换 x/y 后，结果表中的偶极方向和张量下标同时更新。 |
| CH₄，T<sub>d</sub> | A₁+E+2T₂，9 个自由度，4 个基频，其中红外允许 2 个、拉曼允许 4 个。四个实验基频的对称性归属可逐项核对。[NIST 甲烷数据](https://cccbdb.nist.gov/exp2x.asp?casno=74828) |
| CO₂，沿 z，D₄ₕ | A₁g+A₂u+Eᵤ，4 个自由度。A₁g 拉曼允许，A₂u 与二重简并 Eᵤ 红外允许。切换子群后保留自由度总数。[NIST 二氧化碳数据](https://cccbdb.nist.gov/exp2x.asp?casno=124389) |
| 一个有解析解的双原子谐振子 | 用给定键力常数 $k$ 和约化质量 $\mu$ 核验 $\sqrt{k/\mu}/(2\pi c)$。改变质量后核对同位素位移，同步交换两原子的全部输入后波数一致。 |
| 一份具有频率、IR 强度和 Raman 活性的参考输出 | 导入后的模式编号、数值和单位逐项与源表核对。对同一组棒谱改变展宽后，数值积分在约定的积分范围和误差内保持总权重。虚频、缺失强度和零强度在导出后仍可区分。 |

第一阶段已接入 0.5.0 正式版的三语界面、复制与 JSON 导出。回归测试涵盖水分子平面换向、甲烷的简并子空间、CO₂ 的红外与拉曼互斥，以及所有 87 个点群的偏振与张量子空间。数值谱线导入和 Hessian 求解分别列在第二、第三阶段。
